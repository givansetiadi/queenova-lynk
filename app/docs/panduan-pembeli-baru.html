Enam langkah, satu folder aplikasi

Semua toko pembeli dilayani oleh satu aplikasi di public_html/etalase. Setiap pembeli hanya mendapat subdomain baru yang diarahkan ke folder itu, lalu didaftarkan di panel admin bersama token lynk.id miliknya.

1

Minta data ke pembeli

WhatsApp

Kirim pesan berikut. Yang wajib hanya subdomain, token, dan tema pilihan; sisanya boleh menyusul.

Template pesan · minta data

Halo kak Budi, terima kasih sudah order template etalase lynk.id 🙏

Untuk pemasangan, mohon kirimkan:

1. Nama subdomain yang diinginkan (contoh: tokobudi → tokobudi.queenovatech.com)

2. Token API lynk.id: buka lynk.id → Settings → Integrations → API Keys → buat key baru → salin (diawali lynk_sk_…). Token hanya tampil sekali, langsung disalin ya.

3. (Opsional) Nama toko, bio singkat, link foto profil, link sosmed (IG/TikTok/WA)

Token disimpan terenkripsi dan bisa kakak cabut kapan saja dari lynk.id.

2

Buat subdomain

hPanel Hostinger
  1. Login hPanel → pilih website queenovatech.com.
  2. Buka Domains → Subdomains.
  3. Isi nama subdomain: tokobudi.
  4. Centang Custom folder for subdomain → isi public_html/etalase.
  5. Klik Create.
Paling penting: custom folder harus public_html/etalase. Kalau salah, toko tidak akan tampil. Nama menu bisa sedikit berbeda tergantung versi hPanel.
3

Pasang SSL (https)

hPanel Hostinger
  1. Buka Security → SSL.
  2. Cari tokobudi.queenovatech.com → klik Install SSL (gratis).
  3. Tunggu status Active.

Biasanya 5–15 menit. Subdomain yang baru dibuat kadang perlu sampai 1 jam untuk DNS.

5

Cek hasilnya

Browser
  1. Di daftar toko, klik tokobudi → terbuka https://tokobudi.queenovatech.com.
  2. Pastikan nama dan foto benar, produk pembeli muncul (pembukaan pertama perlu beberapa detik).
  3. Klik Beli → harus membuka checkout lynk.id milik Budi, bukan milikmu.
  4. Produk baru belum muncul? Klik Muat ulang di admin.

Perawatan rutin

Setelah toko berjalan

KebutuhanCaranya di admin
Ganti temaUbah → pilih tema lain → simpan. Langsung tampil.
Pembeli ganti tokenUbah → tempel token baru di kolom token. Kosongkan kalau tidak diganti.
Langganan habisNonaktifkan. Data tetap aman, bisa diaktifkan lagi kapan saja.
Pembeli berhenti totalUbah → Hapus permanen. Minta pembeli juga mencabut token di lynk.id.
BackupUnduh data/app.sqlite dan config.php dari File Manager. Simpan berpasangan.
Jangan ubah app_key di config.php. Kalau kunci itu hilang atau berubah, semua token tersimpan tidak bisa dibuka dan harus diinput ulang satu per satu.
