Kenapa perlu?

Pembeli menilai toko dari tampilan pertama.

Halaman lynk.id bawaan rapi, tapi semua toko terlihat mirip. Template ini bikin tokomu punya wajah sendiri, tanpa ribet mengurus produk dua kali.

Tanpa template

  • Tampilan sama seperti toko lain, susah diingat
  • Pembeli harus beli produk satu per satu
  • Produk banyak, pembeli bingung mencari
  • Tidak tahu pembeli datang dari link mana

Pakai template ✦

  • Desain sesuai karakter brand kamu
  • Keranjang: beli beberapa produk, bayar sekali
  • Ada kolom cari, filter harga, dan promo
  • Penjualan dari website tercatat di lynk.id kamu

    FAQ

    Yang sering ditanyakan.

    Masih ada yang bingung? Langsung chat saja, saya jawab.

    Apakah saya tetap pakai akun lynk.id?

    Ya. Produk, pesanan, dan pembayaran tetap di akun lynk.id kamu. Website ini jadi etalase yang lebih cantik, checkout-nya tetap di lynk.id.

    Kalau saya tambah produk baru, harus update website juga?

    Tidak. Produk diambil langsung dari lynk.id, jadi produk baru dan perubahan harga muncul sendiri dalam beberapa menit.

    Apa saja yang perlu saya siapkan?

    Akun lynk.id, API key dari menu Settings → Integrations → API Keys di lynk.id (saya pandu cara membuatnya), foto profil, dan link sosmed yang mau ditampilkan.

    Pembeli bayarnya ke mana?

    Ke lynk.id, sama seperti biasa. Uang masuk ke saldo lynk.id kamu. Website ini tidak menyimpan data pembayaran.

    Bisa pakai domain sendiri?

    Bisa. Kalau kamu punya domain (misalnya namatoko.com), saya bantu sambungkan. Domain dibeli terpisah.

    Bisa minta warna atau detail disesuaikan?

    Bisa. Nama, foto, bio, sosmed, dan teks sudah termasuk. Perubahan warna atau desain lainnya bisa dibicarakan lewat WhatsApp.
